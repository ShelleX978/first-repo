# 🚀 Codespace 使用说明

## 快速启动

1. 在 GitHub 仓库页面点击绿色 **Code** 按钮
2. 选择 **Codespaces** 标签
3. 点击 **Create codespace on main**
4. 等待 2-3 分钟，环境自动配置完成
5. 打开 `buy-me-a-coffee/index.html`
6. 右键 → **Open with Live Server**
7. 浏览器会自动打开预览页面

## 已配置内容

| 项目 | 说明 |
|------|------|
| Node.js 20 | JavaScript 运行时 |
| Live Server | 实时预览服务器（端口 5500）|
| Prettier | 代码格式化（保存时自动格式化）|
| ESLint | 代码检查 |
| HTML CSS Support | HTML/CSS 智能提示 |
| CSS Class Completion | CSS 类名自动补全 |

## 常用快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Shift + P` | 命令面板 |
| `Ctrl + S` | 保存（自动格式化）|
| `Alt + B` | 用 Live Server 打开 |
| `Ctrl + Shift + E` | 文件资源管理器 |
| `Ctrl + \` ` | 终端 |

## 修改后预览

- 用 Live Server 打开后，每次保存文件，浏览器会自动刷新
- 也可以在终端运行 `python3 -m http.server 8080` 启动静态服务器

## 提交代码

1. 左侧点击源代码管理图标（分支形状）
2. 输入提交信息
3. 点击 **Commit**
4. 点击 **Sync Changes** 推送到 GitHub
